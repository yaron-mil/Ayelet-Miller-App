# Ayelet Miller App

אפליקציה מותאמת לנייד ולמחשב לניהול לקוחות, הזמנות והסכמי שירות.

מתוך כל הזמנה ניתן להציג הסכם מלא, להוריד אותו כקובץ PDF, להדפיס או לשתף אותו דרך חלון השיתוף של המכשיר. ההערות הפנימיות והיסטוריית השינויים אינן נכללות בקובץ המופק.

הנתונים נשמרים מקומית בדפדפן עד להפעלת החיבור המאובטח לענן. אין לשמור נתוני לקוחות אמיתיים במאגר GitHub.
